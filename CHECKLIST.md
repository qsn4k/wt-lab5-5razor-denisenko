# WT-5 — чек-лист по методичке

Проверено по PDF-методичке WT-5 и исходному проекту WT-4.

## Реализовано в исходниках

- [x] Проект ASP.NET Core Razor Pages и структура `Pages/`, `wwwroot/`, `Program.cs`.
- [x] Предметная область перенесена из WT-4: Tournament Hub и модель `Player`.
- [x] Общее in-memory хранилище `Data/PlayerStore.cs` с 7 исходными участниками.
- [x] Модель с несколькими свойствами и аннотациями валидации.
- [x] Собственная главная страница с Bootstrap-оформлением и статистикой.
- [x] Список игроков, адаптивные карточки, поиск по никнейму и фильтр по игре.
- [x] Страница создания с `OnGet()`, `OnPost()`, `[BindProperty]`, `ModelState.IsValid` и отображением ошибок.
- [x] Tag Helpers: `asp-page`, `asp-route-id`, `asp-for`, `asp-validation-for`.
- [x] Общий `_Layout.cshtml` и навигация.
- [x] Подробная карточка игрока с проверкой `NotFound()`.
- [x] Редактирование: GET/POST; удаление отдельным POST handler.
- [x] Дополнительная страница топ-3 рейтинга из WT-4.
- [x] Единый киберпанк-интерфейс, hover-эффекты и CSS для широкого и мобильного экрана.
- [x] `Dockerfile` с multi-stage build, `.dockerignore`, переменная `PORT` и привязка к `0.0.0.0`.
- [x] README с маршрутами и инструкциями по запуску и публикации.
- [x] Локальная Git-история с тремя осмысленными коммитами.
- [x] Отчёт и визуальные макеты страниц подготовлены; статический аудит исходников: 25/25 проверок пройдено.

## Не подтверждено в текущей среде

- [ ] `dotnet restore` / `dotnet build` / локальный запуск: в среде подготовки не установлен .NET SDK.
- [ ] Успешная Docker-сборка: Docker CLI отсутствует.
- [ ] Публичный GitHub-репозиторий WT-5: создана только локальная Git-история; удалённый репозиторий не создавался и не запушен.
- [ ] Deployment на Render и URL приложения: не выполнены, поскольку требуют удалённого репозитория и доступа к аккаунту Render.
- [ ] Реальные скриншоты Docker Build, Render Dashboard, успешного deployment и опубликованных страниц: их нельзя достоверно получить до соответствующих действий.

## Что выполнить перед окончательной сдачей

1. Установить .NET SDK 9.0 и проверить `dotnet restore`, `dotnet build`, `dotnet run`.
2. Выполнить `docker build -t wt-lab5-5razor-denisenko .` и проверить URL `http://localhost:10000`.
3. Создать GitHub-репозиторий `wt-lab5-5razor-denisenko`, добавить remote и выполнить `git push -u origin main`.
4. Создать Render Web Service с Runtime `Docker`, дождаться успешного deployment и проверить основные маршруты.
5. Добавить реальный GitHub URL, Render URL и фактические скриншоты в README и отчёт.
