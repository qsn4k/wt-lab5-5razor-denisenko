# WT-5 — Tournament Hub (Razor Pages)

Лабораторная работа WT-5 по дисциплине «Web-технологии». Проект продолжает предметную область WT-4 Tournament Hub, но использует Razor Pages вместо MVC-контроллеров и представлений.

## Возможности

- главная страница с краткой статистикой и лидерами;
- каталог игроков, поиск по никнейму и фильтр по игре;
- подробный профиль участника;
- добавление и редактирование профиля с серверной валидацией;
- удаление через POST-запрос;
- топ-3 игроков по рейтингу;
- общий `PlayerStore` в памяти процесса, Bootstrap и адаптивный неоновый интерфейс;
- Dockerfile для публикации приложения как Render Web Service.


## Основные страницы

- `/` — главная;
- `/Players/Index` — каталог игроков и фильтры;
- `/Players/Create` — создание игрока;
- `/Players/Details?id=1` — профиль и удаление;
- `/Players/Edit?id=1` — редактирование;
- `/Players/Top` — топ-3 по рейтингу.
